# @gonzih/skills-architecture

Architecture and design skills for Claude Code.

## Skills

| Skill | Description |
|-------|-------------|
| `design-narrative` | Write architectural design narratives for projects |
| `building-spec-summary` | Summarize complex building specifications clearly |
| `client-brief` | Write detailed client briefs for architectural projects |
| `permit-memo` | Write permit application memos and supporting documentation |

## Installation

```bash
npx clawdhub@latest install @gonzih/skills-architecture
```

Or manually copy the `skills/` directory to your Claude Code skills location.

## Skills Detail

### design-narrative
Write comprehensive architectural design narratives covering project vision, site response, spatial organisation, material palette, sustainability strategies, and design intent. Suitable for planning submissions, client presentations, and design reviews.

### building-spec-summary
Read and summarize lengthy NBS, CSI, or proprietary building specification documents into clear, plain-English summaries by trade or section. Flags unusual clauses and key requirements.

### client-brief
Conduct a structured briefing interview and produce a formal client brief document. Covers project scope, spatial requirements, budget, programme, and design aspirations. Suitable for project inception.

### permit-memo
Produce formal planning and building permit cover letters, statements of compliance, and supporting memos. Tailored to the relevant authority and jurisdiction.
